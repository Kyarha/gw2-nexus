## Slice 004-03 — combat & movement visibility

**Goal:** Deliver the mockup's **Show overlay** matrix: independently for
**Out of combat** and **In combat**, choose **Always / While moving / Never**.
Combat state comes from the MumbleLink `UiState` bit; "While moving" from
frame-to-frame pointer movement. Persisted. Advances the project's game-state-
aware rendering principle at near-zero read cost. Values per
[Cursor Settings.dc.html](../../designs/cursors_v1.0/Cursor Settings.dc.html)
("BEHAVIOUR" → "Show overlay").

**DoR (Definition of Ready):**
- ✅ 004-01 DONE — the addon draws + persists settings and links against the
  MumbleLink read pattern.
- ✅ MumbleLink read pattern in-tree —
  [notes/src/entry.cpp:56-65](../../../notes/src/entry.cpp) (`ReadCurrentCoordinate`)
  and [notes/src/mumble_link.h](../../../notes/src/mumble_link.h) (`UiState`).

**Acceptance Criteria:**

1. **Two independent visibility modes.** The panel exposes a **3-way choice**
   (Always / While moving / Never) **for each of** Out-of-combat and In-combat —
   a 2×3 setting — persisted to the settings JSON (schema version bumped +
   migrated) and restored next session.
2. **Combat state selects the active mode.** Each frame the addon reads the
   `MumbleContext.UiState` combat bit and applies the matching column's mode
   (in-combat vs out-of-combat). The bit read is a pure predicate over the link
   struct, testable in `cursor-core` against a synthetic `UiState`.
3. **"While moving" tracks pointer motion.** In a "While moving" mode the marker
   shows only when the pointer has moved within a short, defined window
   (frame-to-frame `GetMousePos()` delta above a small threshold) and fades/hides
   when still. The movement predicate + timeout live in `cursor-core`, tested
   with synthetic position sequences.
4. **Safe when the link is unavailable.** If MumbleLink is missing or not yet
   live (`UiTick == 0`), the addon degrades to a defined default (treat as
   out-of-combat), never flickering or crashing — mirroring Notes' `nullopt`
   handling.

**Assumptions (per-slice, drives `frame_review`):**
- **A3 (this slice) — combat is `UiState` bit 4 (`0x10`).** Documented GW2
  `UiState` maps `IsInCombat` to bit 4; the full `MumbleContext` layout is
  runtime-unverified in `mumble_link.h`. **Confirmed in-game** (toggle combat,
  observe the column switch) before relied on; the mask is a named `cursor-core`
  constant so a correction is one line.
- **A6 (this slice) — "While moving" is a movement delta.** No API exposes
  "cursor is moving"; it is derived from `GetMousePos()` deltas. During mouse-look
  the OS cursor is locked to centre so deltas go to zero and the marker hides —
  acceptable for v1.0 (spec A6).

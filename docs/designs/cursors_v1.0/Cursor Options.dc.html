Four tapered spokes point inward to a gap, funneling your eye to the exact tip. White + dark outline reads on any background color.

VIOLET · STATIC

A dashed ring in a rare violet hue. The broken dashes read differently from GW2's solid rings, so it stands out without spinning.

5
Soft Halo
TEAL · GLOW

A soft glowing orb behind the pointer — the closest to the reference plugin. Least intrusive, but can wash out over bright water; lower the opacity there.

Design rule shared across all five: a dark outline so the shape survives on any color, and a hue GW2's own effects avoid (no red — that reads as enemy AoE). Tell me which number you like (or a mix) and I'll produce it as a ready-to-drop PNG set.
